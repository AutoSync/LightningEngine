# Regras para adição de features

- As features devem ser adicionadas seguindo a hierarquia do jogo, garantindo que cada elemento seja carregado no momento adequado.
- As features devem ser organizadas de forma modular, permitindo fácil manutenção e expansão futura.
- As features devem ser testadas individualmente para garantir que não causem conflitos ou problemas de desempenho.
- Completa integração com UI e HUD para garantir uma experiência de usuário consistente.
- As features devem ser documentadas adequadamente para facilitar a compreensão e colaboração entre os membros da equipe.
